# Guide utilisateur

Guide pas à pas pour les **marchands Shopify** utilisant pilotCFO (sans jargon technique).

## Qu'est-ce que pilotCFO ?

pilotCFO analyse la santé financière de votre boutique Shopify : rentabilité, trésorerie, dépenses publicitaires et risques. Ce n’est pas un simple chatbot — les chiffres viennent de **votre boutique** et du **profil que vous renseignez**.

## Avant de commencer

Vous aurez besoin de :

- Une adresse e-mail
- Une boutique Shopify (idéalement une boutique de test fournie par Shopify si vous débutez)
- Environ 15 minutes pour le premier parcours

## Étape 1 — Créer un compte

1. Allez sur l’adresse de l’application (ex. `https://app.pilotcfo.com`).
2. Cliquez sur **S’inscrire**.
3. Entrez votre e-mail et mot de passe.
4. Validez l’e-mail si demandé.

## Étape 2 — Onboarding (présentation)

Six écrans courts présentent l’outil. Vous pouvez avancer rapidement ; l’objectif est de configurer votre entreprise (nom, pays, devise).

## Étape 3 — Questionnaire CFO

Six questions sur :

- Votre chiffre d’affaires
- Vos marges et coûts produits
- Vos dépenses publicitaires (Meta, Google, etc.)
- Votre trésorerie et dettes
- Vos objectifs sur 12 mois

À la fin, un **profil financier** s’affiche avec des tags (ex. croissance, pression trésorerie). Vous pouvez ouvrir l’**AI CFO** avec une question suggérée.

## Étape 4 — Connecter Shopify

1. Menu **Paramètres** (Settings).
2. Section **Shopify**.
3. Entrez le nom de votre boutique : `maboutique` (sans `https://`).
4. Validez — vous êtes redirigé vers Shopify pour autoriser l’accès.
5. Après validation, vous revenez sur pilotCFO : la boutique est **connectée**.

### Si la connexion échoue

- Vérifiez que l’adresse ressemble à `maboutique.myshopify.com`.
- Utilisez une vraie boutique Shopify (pas un simple nom de domaine externe).
- Réessayez depuis Paramètres.

## Étape 5 — Synchroniser les données

1. Toujours dans **Paramètres → Shopify**.
2. Regardez l’indicateur de sync :
   - ⚪ Jamais synchronisé
   - 🟡 En cours ou données anciennes
   - 🟢 À jour
3. Cliquez sur **Synchroniser** (Sync now).
4. Attendez la fin (peut prendre 1 à 5 minutes selon le volume de commandes).

Les tableaux de bord se remplissent une fois les données importées.

## Étape 6 — Explorer les tableaux de bord

| Menu | Ce que vous y trouvez |
|------|------------------------|
| **Vue d’ensemble** | Chiffres clés et alertes |
| **Santé financière** | Score global et sous-scores |
| **Rentabilité** | Marges, coûts, produits |
| **Trésorerie** | Runway, cash, dettes |
| **Prévisions** | Tendances 3 / 6 / 12 mois |
| **AI CFO** | Posez des questions en français |
| **Rapports** | Rapports mensuels |
| **Paramètres** | Shopify, abonnement, langue |

## Étape 7 — Utiliser l'AI CFO

Exemples de questions :

- « Pourquoi ma marge baisse ? »
- « Puis-je augmenter mon budget Meta ? »
- « Quels sont mes principaux risques ? »
- « Puis-je embaucher ? »

Les réponses s’appuient sur vos données. Si Shopify n’est pas connecté ou pas synchronisé, l’AI CFO vous le dira.

## Changer la langue

Dans **Paramètres**, utilisez le sélecteur **Français / English**. La navigation et les paramètres suivent la langue choisie.

## Abonnement

- Essai gratuit limité dans le temps.
- Pour continuer : choisir un plan dans **Paramètres → Abonnement**.
- Paiement sécurisé par Stripe ; factures via le portail client.

## Bonnes pratiques

| Pratique | Pourquoi |
|----------|----------|
| Sync après grosse journée de ventes | Données fraîches |
| Mettre à jour le questionnaire si votre CA change | Prévisions plus réalistes |
| Vérifier les **alertes** sur la vue d’ensemble | Agir tôt sur les risques |

## Limites importantes

- pilotCFO **ne remplace pas** un expert-comptable ou un avocat fiscal.
- Les prévisions sont des **estimations**, pas des garanties.
- Les coûts produits dépendent de ce que Shopify contient ; complétez les coûts dans Shopify si possible.
